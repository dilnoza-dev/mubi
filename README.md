# Mubi — onlayn do'kon (demo)

Erkaklar va ayollar uchun kiyim va aksessuarlar onlayn do'konining demo versiyasi.

- Katalog, qidiruv, filtrlar va saralash
- Mahsulot sahifasi: rang bo'yicha fotolar, o'lchamlar jadvali
- Savatcha (brauzerda saqlanadi) va buyurtma rasmiylashtirish
- Toshkent bo'ylab kuryer (20 000 so'm) yoki do'kondan olib ketish

Bu demo: buyurtmalar hech qayerga yuborilmaydi, to'lov olinmaydi.
Barcha ma'lumotlar namunaviy. Fotosuratlar: [Unsplash](https://unsplash.com) (bepul litsenziya).

Sayt bitta `index.html` faylidan iborat, build kerak emas.
